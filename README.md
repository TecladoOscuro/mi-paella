# 🥘 Mi Paella

**Guía de paellas tradicionales — recetas, ingredientes y modos de cocción**

PWA mobile-first para consultar recetas de paella y arroces tradicionales mediterráneos. Instalable como widget en iPhone/Android.

🌐 **[tecladooscuro.github.io/mi-paella](https://tecladooscuro.github.io/mi-paella/)**

---

## Qué incluye

- **17 recetas tradicionales** — desde pollo y verduras hasta paella valenciana con caracoles
- **2 modos de cocción** en cada receta: ⚡ Inducción y 🔥 Parrilla/BBQ
- **Fases de calor detalladas** con tiempos y potencia por método
- **Modo lista** y **modo compra** con checklist que persiste en el dispositivo
- **Filtro por tags**: carne, marisco, verdura, principiante, celebración, tradicional…
- **PWA** instalable, funciona sin conexión, interfaz pensada para móvil

## Tech

## Desarrollo

```bash
npm install
npm run dev
npm run build
```

Push a `main` → GitHub Actions despliega a Pages automáticamente.
